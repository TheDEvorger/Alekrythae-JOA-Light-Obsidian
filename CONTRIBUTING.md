# Contributing

Thanks for your interest in JOA Light. Please first review the [license](./LICENSE): this is proprietary, source-available software, **not open source**. The license does not grant general redistribution or derivative publication rights. Its **Section 22** sets out broad rights granted to the licensor by intentionally submitted contributions.

- For bugs, file a minimal reproducible issue without publishing vault contents or personal databases.
- For feature proposals, describe the writing problem before proposing code.
- Before submitting code or artwork, verify that you can legally grant the rights specified by Section 22.
- For accepted, authorized changes, keep architecture boundaries and regression tests intact; generated `main.js` and `styles.css` should be rebuilt from sources.

The licensor is not obliged to review, accept or merge contributions. Contact the licensor through the details in `LICENSE` for requests beyond these permissions.
