It is **not an application screenshot**. Publication/reuse is governed by applicable creator rights and the project's license; independently verify rights before commercial reuse.

- `assets/showroom/*.webp`: six UI screenshots supplied by the project owner, transcoded from 1920×1080 PNG to web-friendly WebP without changing their depicted content. They illustrate a local JOA Light session; confirm that visible character names and artwork are authorized for publication.

- `background-images/default.webp`: optimized original fantasy landscape supplied by the project owner for the F3 studio. Confirm publication rights before first release.
- `audio/MV1.mp3`–`MV240.mp3`: voice recordings supplied in the parent JOA project archive, paired exactly with `Assets/mv-voice/mv-lines.json`; permissions to distribute recordings must be confirmed before public release.
- `src/domain/d240/CanonicalD240Lines.ts`: 240 canonical source sentences and their roll indices, retained exactly from the existing project. These are **not** public-domain writing prompts.

No actual user notes, personal portraits or private `.sqlite` files belong in the public repository.
